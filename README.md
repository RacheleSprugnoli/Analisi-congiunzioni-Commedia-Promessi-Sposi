# Analisi di _finché_ e _poiché_ nella Commedia e nei Promessi-Sposi

Questo repository contiene il file con le annotazioni delle funzioni di _finché_ e _poiché_ estratti dalla _Commedia_ di Dante Alighieri e dalle tre redazioni dei _Promessi Sposi_ di Alessandro Manzoni.
L'annotazione fa parte dello studio presentato alla conferenza SLI 2025 e in pubblicazione:
- Corbetta, Claudia e Sprugnoli, Rachele. "Alla ricerca della grammaticalizzazione: l’evoluzione di finché e poiché in Dante e Manzoni attraverso l'uso di risorse annotate". Atti del LVIII Congresso internazionale di studi della Società di Linguistica Italiana (L'Aquila, 11-13 settembre 2025).
